# استمارة التسجيل الإلكترونية المتصلة بقوقل شيت (Google Sheets Form)

مشروع استمارة تسجيل إلكترونية متكاملة ومستقلة، مستخرجة ومطورة لتتصل مباشرة بجدول بيانات **Google Sheets** ومجلد **Google Drive** وإشعارات **Telegram**، ومجهزة بالكامل للنشر الفوري على **Vercel.com** ورفعها إلى مستودع جديد في **GitHub**.

---

## ✨ المميزات الرئيسية

- ⚡ **اتصال مباشر بـ Google Sheets**: حفظ فوري للبيانات في ورقة العمل `RegistrationAnswers` وتوليد رقم مرجعي فريد لكل مشترك.
- 📁 **رفع الملفات والصور إلى Google Drive**: دعم رفع المستندات (PDF, Word, Images) أو التقاط صور مباشرة بكاميرا الهاتف/الحاسوب وحفظها في مجلد درايف محدد.
- 📱 **إشعارات Telegram فورية**: إرسال تفاصيل كل تسجيل جديد فوراً إلى قناتك أو مجموعة العمل على تلغرام.
- 🌍 **دعم متعدد اللغات**: يدعم العربية (افتراضي RTL)، الإنجليزية (EN)، والتايلاندية (TH) بسلاسة.
- 🛡️ **حماية ضد السبام (Anti-Spam)**: حقل Honeypot ذكي وفحص زمني لمنع روبوتات الإعلانات المزعجة.
- 🖨️ **إيصال توثيق و QR Code**: بطاقة نجاح تفاعلية مع كود QR للتحقق وإمكانية النسخ والمشاركة عبر واتساب أو الطباعة كـ PDF.
- ☁️ **جاهز للنشر على Vercel**: معد للعمل كصفحة سريعة خفيفة أو مع دوال Serverless (`/api/register`).

## 🚀 طريقة رفع المشروع إلى مستودع جديد في GitHub

افتح موجه الأوامر (Terminal) في مجلد هذا المشروع ونفذ:

```bash
# 1. تهيئة المستودع
git init

# 2. إضافة جميع الملفات
git add .

# 3. حفظ التغييرات
git commit -m "Initial commit: Standalone Google Sheets Form"

# 4. تغيير اسم الفرع للرئيسي
git branch -M main

# 5. ربط المستودع برابط مستودعك الجديد في GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

# 6. الرفع إلى GitHub
git push -u origin main
```

## 🌐 طريقة النشر على موقع Vercel.com

1. ادخل إلى موقع [Vercel.com](https://vercel.com) وسجل الدخول بحساب GitHub الخاص بك.
2. اضغط على زر **Add New...** ثم اختر **Project**.
3. اختر المستودع الجديد الذي رفعته للتو ثم اضغط **Import**.
4. (اختياري) في قسم **Environment Variables** أضف المتغيرات التالية إن أردت تخصيصها:
   - `VITE_SPREADSHEET_ID`: معرف جدول قوقل شيت الخاص بك.
   - `VITE_GOOGLE_SCRIPT_URL`: رابط تطبيق الويب من Google Apps Script.
   - `VITE_DRIVE_FOLDER_ID`: معرف مجلد Google Drive.
5. اضغط على **Deploy** وخلال أقل من دقيقة ستحصل على رابط الموقع المنشور ويعمل مباشرة!

---

## 📝 خطوات تثبيت كود Google Apps Script في قوقل شيت

1. افتح جدول بيانات Google Sheets الخاص بك.
2. من القائمة العلوية اختر: **الإضافات (Extensions)** > **تطبيقات سكريبت (Apps Script)**.
3. الصق كود سكريبت الموجود في ملف `src/data/appsScriptCode.ts` كاملاً.
4. اضغط على زر **نشر (Deploy)** الأزرق بأعلى الشاشة، ثم **نشر جديد (New deployment)**.
5. اختر نوع النشر: **تطبيق ويب (Web app)**.
6. في خانة "من يملك حق الوصول" (Who has access)، اختر: **أي شخص (Anyone)**.
7. اضغط **نشر (Deploy)** وانسخ الرابط الناتج (ينتهي بـ `/exec`)، ثم ضعه في إعدادات الفورم.
